# BI-PVM-Din-mico
O PVM Dinâmico é o aplicativo QlikSense que consolida, em um único painel self-service, as análises de Preço-Volume-Mix (PVM).O objetivo é permitir que o usuário escolha, quais bases comparar, qual tipo de PVM analisar, qual dimensão usar e quais indicadores exibir sem que dependa de outros aplicativos e consiga realizar análises mais avançadas.
